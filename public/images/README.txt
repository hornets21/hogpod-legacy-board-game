# 🖼️ Folder สำหรับใส่รูปภาพของเกม (Image Directory)

นำไฟล์รูปภาพของคุณมาวางไว้ในโฟลเดอร์ย่อยตามหมวดหมู่ได้เลย:

- `public/images/houses/` — รูปโลโก้หรือภาพแทนของ 4 บ้าน (`watrat.png`, `plodfindr.png`, `anal.png`, `slarf.png`)
- `public/images/monsters/` — รูปมอนสเตอร์และบอส (`chicky.png`, `tao_mono.png`, `grand_boss.png`)
- `public/images/items/` — รูปไอเทม ไม้กายสิทธิ์ เสื้อเกราะ เครื่องราง ยา (`wand_common.png`, `potion_heal.png`)
- `public/images/pets/` — รูปสัตว์วิเศษ (`hisoka.png`, `okarun.png`, `bank.png`)
- `public/images/cards/` — รูปการ์ด หรือองค์ประกอบอื่นๆ
- `public/images/npc/` — รูปภาพ NPC พ่อค้า และตัวละครอื่นๆ (`shopkeeper.png`)
